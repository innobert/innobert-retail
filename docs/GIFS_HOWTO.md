# 📸 Cómo agregar GIFs demostrativos

Esta carpeta está destinada a almacenar GIFs demostrativos de las funcionalidades del software.

## 🎬 Herramientas recomendadas para grabar GIFs

### Windows
- **[ScreenToGif](https://www.screentogif.com/)** - Herramienta especializada en GIFs
- **[ShareX](https://getsharex.com/)** - Captura de pantalla avanzada
- **[OBS Studio](https://obsproject.com/)** - Grabación profesional

### Linux
- **[Peek](https://github.com/phw/peek)** - Grabador de pantalla a GIF
- **[SimpleScreenRecorder](https://www.maartenbaert.be/simplescreenrecorder/)** - Grabación de pantalla
- **[ffmpeg](https://ffmpeg.org/)** - Conversión de video a GIF

### macOS
- **[GIF Brewery](https://gifbrewery.com/)** - Especializado en GIFs
- **[Licecap](https://www.cockos.com/licecap/)** - Simple y directo

## 📋 Pasos para crear GIFs

### 1. Grabar la pantalla
- Abre ScreenToGif (Windows) o Peek (Linux)
- Selecciona el área a grabar
- Graba la acción (máximo 10-15 segundos por GIF)

### 2. Guardar como GIF
- Exporta el archivo como GIF
- Nombre recomendado: `nombre_funcionalidad.gif`
- Tamaño máximo recomendado: 5-10 MB

### 3. Colocar en la carpeta correcta
- Copia el GIF a: `docs/gifs/`
- Ejemplo: `docs/gifs/agregar_producto.gif`

## 💡 Consejos

- Mantén los GIFs **cortos** (máximo 15 segundos)
- **Comenta en voz** o agrega texto superpuesto para mayor claridad
- Asegúrate de usar **resolución clara** (mínimo 720p)
- Prueba el GIF antes de subirlo
- Usa **nombres descriptivos** en inglés o español
