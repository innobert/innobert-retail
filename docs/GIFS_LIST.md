## 💡 Tips para grabar

### Herramientas recomendadas
- **Windows:** ScreenToGif
- **Linux:** Peek
- **macOS:** GIF Brewery

### Checklist antes de grabar
- [ ] Asegúrate de que el software esté listo con datos de prueba
- [ ] Prueba la grabación en baja resolución primero
- [ ] Graba en resolución mínima 1280x720
- [ ] Habla mientras grabas o agrega texto descriptivo
- [ ] Mantén cada GIF entre 6-15 segundos
- [ ] Guarda con el nombre exacto de la lista

### Checklist después de grabar
- [ ] Verifica que el GIF se ve nítido
- [ ] Confirma que el tamaño es menor a 10 MB
- [ ] Prueba que la ruta relativa funciona en GitHub
- [ ] Añade el archivo a `docs/gifs/`
